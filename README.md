# Mutual Fund Analytics

## Bluestock Fintech Internship Capstone Project

An end-to-end Mutual Fund Analytics project covering data ingestion, ETL, SQL analysis, exploratory data analysis, fund performance evaluation, advanced risk analytics, investor analytics, and interactive Power BI dashboards.

## Project Overview

This project analyses mutual fund industry trends, fund performance, investor behaviour, SIP activity, portfolio concentration, and financial risk metrics.

The complete workflow includes:

- Data ingestion and preprocessing
- Data cleaning and validation
- SQLite database creation
- SQL business analysis
- Exploratory Data Analysis
- Fund performance analytics
- VaR and CVaR analysis
- Rolling 90-Day Sharpe Ratio
- Investor cohort analysis
- SIP continuity analysis
- Risk-based fund recommender
- Sector concentration using HHI
- Interactive Power BI dashboard
- Final report and presentation
